# Skenario Pengujian Graybox Modul Company Profile & Employees

Pengujian dilakukan untuk memastikan bahwa operasional pada modul Company Profile & Employees dapat dilaksanakan sesuai dengan kebutuhan sistem. Daftar *endpoint* pada modul *company* digunakan untuk mengelola profil perusahaan, data karyawan, undangan karyawan baru, serta konfigurasi integrasi perusahaan. Owner dapat mengakses dan memperbarui profil perusahaan, melihat daftar dan detail karyawan, mengeluarkan karyawan, serta mengundang karyawan baru. Riwayat undangan dan konfigurasi integrasi juga dapat dikelola melalui modul ini. Seluruh endpoint memerlukan token otorisasi dan menerapkan pembatasan hak akses berbasis peran, terutama untuk peran owner. Fokus pengujian diletakkan pada fungsionalitas utama, validasi input, serta kepatuhan terhadap batasan hak akses.
