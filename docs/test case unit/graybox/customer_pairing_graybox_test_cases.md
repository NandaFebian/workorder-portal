# Skenario Pengujian Graybox Modul Customer Pairing

Pengujian dilakukan untuk memastikan bahwa operasional pada modul Customer Pairing dapat dilaksanakan sesuai dengan kebutuhan sistem. Daftar *endpoint* pada modul *customer pairing* digunakan untuk mengelola proses penghubungan (pairing) akun pelanggan melalui mekanisme OAuth. Client dapat memulai proses OAuth pairing, menyelesaikan proses pairing, melihat daftar akun yang telah ter-pair, serta melepaskan akun yang sudah ter-pair. Endpoint khusus perusahaan memungkinkan akses terhadap daftar akun ter-pair di perusahaan tertentu. Seluruh endpoint memerlukan token otorisasi dan menerapkan pembatasan hak akses berbasis peran (role-based access control). Fokus pengujian diletakkan pada fungsionalitas utama, validasi input, serta kepatuhan terhadap batasan hak akses.
