# Skenario Pengujian Graybox Modul Memberships & Codes

Pengujian dilakukan untuk memastikan bahwa operasional pada modul Memberships & Codes dapat dilaksanakan sesuai dengan kebutuhan sistem. Daftar *endpoint* pada modul *memberships* digunakan untuk mengelola kode membership dan data keanggotaan pengguna. Owner dapat mengunggah kode membership dalam bentuk file dan menghapus kode yang telah dibuat. Client dapat melakukan klaim kode membership untuk mendapatkan akses ke layanan perusahaan. Endpoint daftar membership menyajikan seluruh data keanggotaan yang tersedia. Seluruh endpoint memerlukan token otorisasi dan menerapkan pembatasan hak akses berbasis peran (role-based access control). Fokus pengujian diletakkan pada fungsionalitas utama, validasi input, serta kepatuhan terhadap batasan hak akses.
