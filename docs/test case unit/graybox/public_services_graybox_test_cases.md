# Skenario Pengujian Graybox Modul Public Services

Pengujian dilakukan untuk memastikan bahwa operasional pada modul Public Services dapat dilaksanakan sesuai dengan kebutuhan sistem. Daftar *endpoint* pada modul *public services* digunakan untuk menyediakan akses publik terhadap informasi perusahaan dan layanan yang tersedia bagi pengguna client tanpa memerlukan autentikasi. Endpoint intake form publik memungkinkan pengambilan formulir pendaftaran layanan secara terbuka. Daftar perusahaan, detail perusahaan, dan layanan perusahaan dapat diakses oleh siapa saja untuk keperluan penelusuran layanan. Karena bersifat publik, endpoint ini tidak memerlukan token otorisasi namun tetap perlu diuji terhadap validasi parameter dan penanganan kesalahan. Fokus pengujian diletakkan pada fungsionalitas utama, validasi parameter, serta ketersediaan data yang akurat.
