# Skenario Pengujian Graybox Modul Services (Owner CRUD)

Pengujian dilakukan untuk memastikan bahwa operasional pada modul Services dapat dilaksanakan sesuai dengan kebutuhan sistem. Daftar *endpoint* pada modul *services* digunakan untuk mengelola data layanan yang dimiliki oleh perusahaan. Owner dapat melakukan operasi CRUD (Create, Read, Update, Delete) terhadap layanan, mengaktifkan atau menonaktifkan layanan, serta membuat work order dari layanan yang tersedia. Endpoint intake form menyediakan formulir pengisian data layanan untuk staff. Seluruh endpoint pada modul ini memerlukan token otorisasi dan menerapkan pembatasan hak akses berbasis peran, terutama untuk peran owner. Fokus pengujian diletakkan pada fungsionalitas utama, validasi input, serta kepatuhan terhadap batasan hak akses.
