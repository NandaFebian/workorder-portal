# Skenario Pengujian Graybox Modul Templates

Pengujian dilakukan untuk memastikan bahwa operasional pada modul Templates dapat dilaksanakan sesuai dengan kebutuhan sistem. Daftar *endpoint* pada modul *templates* digunakan untuk menyediakan akses terhadap template layanan berdasarkan tipe perusahaan. Owner dapat melihat daftar tipe perusahaan yang tersedia, menelusuri layanan berdasarkan tipe perusahaan, melihat preview template layanan, serta menghasilkan layanan baru dari template yang dipilih. Seluruh endpoint memerlukan token otorisasi dan menerapkan pembatasan hak akses berbasis peran (role-based access control). Fokus pengujian diletakkan pada fungsionalitas utama, validasi input, serta kepatuhan terhadap batasan hak akses.
