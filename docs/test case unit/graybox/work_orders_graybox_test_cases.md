# Skenario Pengujian Graybox Modul Work Orders

Pengujian dilakukan untuk memastikan bahwa operasional pada modul Work Orders dapat dilaksanakan sesuai dengan kebutuhan sistem. Daftar *endpoint* pada modul *work orders* digunakan untuk mengelola siklus hidup work order secara menyeluruh mulai dari pembuatan, konfigurasi, penugasan staff, persetujuan, penolakan, pembatalan, pelaksanaan, hingga penyelesaian atau kegagalan. Owner dan manager dapat melakukan berbagai aksi transisi status terhadap work order. Staff yang ditugaskan dapat memulai dan menyelesaikan pekerjaan. Modul ini juga menyediakan akses terhadap laporan work order. Seluruh endpoint memerlukan token otorisasi dan menerapkan pembatasan hak akses berbasis peran (role-based access control). Fokus pengujian diletakkan pada fungsionalitas utama, validasi input, transisi status, serta kepatuhan terhadap batasan hak akses.
